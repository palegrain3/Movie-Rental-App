# Movie Rental front end

1. Run `INFSCI_1500_project_code.sql` in MySQL Workbench to create and fill the database.
2. `pip install -r requirements.txt`
3. Set your MySQL login, then start the app:
   - Windows (PowerShell): `$env:DB_PASSWORD="yourpassword"; python app.py`
   - Mac/Linux: `DB_PASSWORD=yourpassword python app.py`
   (optional: DB_HOST, DB_USER, DB_NAME; defaults are localhost / root / movie_rental)
4. Open http://127.0.0.1:5000
